🔧 FIXER EXPRESS — 3 corrections critiques

❌ PROBLÈME 1 : config.js manque CONFIG + window.CONFIG

Ajoute ceci dans ton config.js, juste après SUBJECT_CONFIG :

const CONFIG = {
  LESSONS_COUNT: 20
};

Et dans le if (typeof window !== "undefined") à la fin, ajoute :

window.CONFIG = CONFIG;

❌ PROBLÈME 2 : data-loader.js écoute 'coreInitialized' au lieu de 'coreReady'

Dans data-loader.js, remplace cette ligne :

EventBus.on('coreInitialized', loadLessons);

Par :

EventBus.on('coreReady', loadLessons);

(Il y en a 2 endroits à corriger — recherche "coreInitialized" et remplace par "coreReady")

❌ PROBLÈME 3 : data-loader.js utilise CONFIG.LESSONS_COUNT sans vérification

Dans data-loader.js, remplace :

for (let i = 1; i <= CONFIG.LESSONS_COUNT; i++) {

Par :

const count = (typeof CONFIG !== 'undefined' && CONFIG.LESSONS_COUNT) 
  ? CONFIG.LESSONS_COUNT 
  : 20;
for (let i = 1; i <= count; i++) {
